## ✨ Features
* **Selective Batch Processing:** Load all shape keys into a dynamic UI list and use checkboxes to target only the ones you want to modify.
* **Custom Prefixes & Suffixes:** Easily append identifiers like `Chaqueta-` or `-Pants` to organize clothing layers, facial morphs, and corrective shapes.
* **Safe & Non-Destructive:** Automatically ignores the `Basis` key to preserve your base mesh. Built-in logic prevents duplicate prefixes/suffixes if applied multiple times.
* **Undo Support:** Full integration with Blender's undo system (`Ctrl + Z`) allows you to revert accidental naming mistakes instantly.
* **Seamless UI:** Operates entirely from a clean, unobtrusive panel in the 3D Viewport Sidebar (N-Panel).
